## About Me

I am a full stack developer with experience in modern web applications built with Next.js, React, and TypeScript, as well as WordPress and PHP projects.

I work on websites, web systems, API integrations, payment flows, carrier integrations, authentication, admin dashboards, and operational tooling.

My focus is to build organized, scalable, and production-ready systems that are easy to maintain and evolve.
